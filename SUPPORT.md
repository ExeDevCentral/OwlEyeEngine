# Support Policy

Thank you for exploring and using this project! Here are the official resources to get help, report issues, and ask questions.

## Getting Help

- **Documentation**: Consult the [README.md](README.md) for quickstart, usage instructions, prerequisites, and examples.
- **Issue Tracker**: If you encounter unexpected behavior or need an enhancement, please verify existing issues before submitting a new one via our issue templates.
- **Questions & Discussions**: For architecture discussions, setup questions, or use-case inquiries, open an issue labeled with `question`.

## Security

If you discover a security-related vulnerability, please do **NOT** disclose it in a public issue. Review our [SECURITY.md](SECURITY.md) for our coordinated private vulnerability disclosure process.

## Response & Maintenance

Community issues and questions are reviewed periodically. Please provide detailed reproduction steps and logs when opening tickets to help us assist you quickly.
