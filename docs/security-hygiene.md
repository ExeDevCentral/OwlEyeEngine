# Security Hygiene & Pre-Flight Checks — OwlEyeEngine

Pre-flight security checklist for contributors and automated environments:

- [x] Zero hardcoded API keys, passwords, or tokens in source control.
- [x] Environment-specific configurations managed via `.env` or CI secrets.
- [x] Dependencies audited for reported CVEs via automated scanners.
- [x] Least-privilege execution principles applied to service definitions.
