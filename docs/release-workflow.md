# Release & Versioning Workflow — OwlEyeEngine

Release life cycle for `OwlEyeEngine`:

1. **Feature Freeze & Staging**: Changes merged to default branch after verification.
2. **Semantic Tagging**: Releases tagged with standard semantic version tags (`vMAJOR.MINOR.PATCH`).
3. **Artifact Generation**: Distribution bundles generated and verified against integrity checksums.
